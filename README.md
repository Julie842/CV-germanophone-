# CV-germanophone

Projet personnel : CV en allemand

Ce projet contient le code source de mon CV au format Web (HTML5 et CSS3). Le fichier principal est conçu sous la forme d'un tableau structuré avec une mise en page bi-colonne (sidebar + zone principale), optimisé pour l'affichage écran et l'impression/export PDF au format A4.

🔍 Aperçu du projet :
Le CV est rédigé en allemand et s'adresse principalement à des recruteurs dans le cadre d'une recherche de stage de 4 semaines. 
Il comprend :
En-tête et barre latérale (sidebar) : photo de profil, coordonnées, compétences techniques (HTML5, CSS3, JS, etc.), langues, points forts, secourisme et centres d'intérêt.
Section principale :
Recherche active de stage.
Formations (Skill & You, Konexio).
Expériences professionnelles (Radio France, SCP DENS-VIEL).
Certifications récentes (IBM SkillsBuild, Google / Coursera).

🛠️ Technologies utilisées :
HTML5 : structure sémantique du document.
CSS3 : stylisation sur mesure sans framework externe.
Rendu bi-colonne via display: table / display: table-cell.
Directives @page pour la gestion du format A4 à l'impression.
Palette de couleurs professionnelle (#2c3e50, #3498db, #ffffff, #fafafa).
